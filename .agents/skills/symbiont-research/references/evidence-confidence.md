# Evidence confidence
- **High:** current authoritative primary evidence, directly relevant, strongly corroborated, with no unresolved material conflict.
- **Medium:** credible but incomplete, indirect, older, partly corroborated, or affected by a disclosed conflict.
- **Low:** weak, preliminary, materially conflicting, discovery-only, or insufficiently verified.

Label each claim Fact, Inference, Estimate, or Recommendation. Missing evidence is an unknown, not a conclusion. Retain conflicting evidence and state what would resolve it.
