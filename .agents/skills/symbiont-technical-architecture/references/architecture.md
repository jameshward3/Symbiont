# Architecture standard
Capture outcome, users, portfolio, use cases, systems, data, integrations, volume, latency, availability, security, privacy, retention, interoperability, standards, budget, schedule, acceptance, and support. Current state records systems, owners, functions, data, interfaces, permissions, failure modes, constraints, debt, authoritative sources, undocumented links, and vendors. Mark each claim Verified, Inferred, Assumed, or Unknown. Target state defines principles, components, boundaries, flows, identity, environments, observability, backup, recovery, scale, performance, security, maintainability, exit strategy, and stages.
