# Taxonomy and identifiers

Business areas are Executive, Sales, Marketing, Delivery, Technical, Operations, Research, AI, and Archive. Use only POL, SOP, STD, TPL, CHK, FRM, RPT, DEC, MTG, DEL, DAT, AUT, AGT, and RES asset types.

Controlled assets use `SYM-[AREA]-[TYPE]-[NNN]`. Reserve existing identifiers; never renumber issued records. Use `EXE`, `SAL`, `MKT`, `DEL`, `TEC`, `OPS`, `RES`, `AI`, and `ARC` area codes. Projects use `PRJ-[YYYY]-[NNN]`, opportunities `OPP-[YYYY]-[NNN]`, clients `CLI-[NNN]`, decisions `DEC-[YYYY]-[NNN]`, agents `AGT-[NNN]`, and automations `AUT-[NNN]`.

Controlled filenames use `[Project-or-Asset-ID]_[Document-Type]_[Short-Title]_[YYYY-MM-DD]_v[Major.Minor].[ext]`. Use ISO dates, hyphens inside titles, underscores between fields, and no spaces. Never use `final`, `latest`, `new`, `revised`, `final-final`, or unexplained initials.
