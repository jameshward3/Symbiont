# Agent handoffs

Every handoff includes work ID, shared goal ID, correlation ID, objective, authoritative inputs, classification, permitted use, version and lifecycle, required output, acceptance criteria, owner, due date, and escalation rule.

AGT-005 supplies only authorized, quality-qualified knowledge. It supports AGT-001 governance; AGT-002 sales standards and handoff knowledge; AGT-003 project records and lessons; AGT-004 standards, checklists, and review evidence; AGT-006 financial procedures; AGT-007 source libraries; AGT-008 automation history; and AGT-009 approved fit criteria and evidence.

Reject incomplete handoffs into Draft or Review. Never imply a database write, notification, approval, assignment, or delivery occurred without verifiable evidence.
