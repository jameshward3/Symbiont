# Automation release gates

Production Ready requires all 25 controls: automation ID; named owner; documented process; approved purpose; baseline volume, time, and error rate; input and output definitions; source-of-truth mapping; data classification; least privilege; test set; approval boundaries; audit logging; monitoring; failure alert; timeout behavior; retry policy; idempotency strategy; duplicate prevention; budget and rate limits; rollback plan; kill switch; recovery procedure; success target; review date.

Record each control as Present, Missing, Failed, or Not Applicable with evidence and approver. Not Applicable needs written rationale. Any missing or failed control makes the automation Draft, Pilot, or Not Ready. Release assessment recommends; a human approves production deployment.
