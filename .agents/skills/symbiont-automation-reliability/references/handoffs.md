# Reliability handoffs

Every incident handoff includes incident ID, severity, automation and run IDs, shared goal ID, correlation ID, detected time, affected systems and records, evidence, containment status, business impact, owner, decision required, next action, and recovery target.

Route reliability/risk reporting to AGT-001; CRM/proposal/pipeline to AGT-002; project workflows to AGT-003; QA tools to AGT-004; knowledge/link checks to AGT-005; finance monitoring without payments to AGT-006; research sources to AGT-007; opportunity scans to AGT-009. Preserve acceptance criteria and acknowledgement evidence.
