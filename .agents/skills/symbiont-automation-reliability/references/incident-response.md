# Incident response

Use Detected → Triaged → Contained → Recovering → Monitoring → Resolved → Closed; also Blocked and Reopened. Detect, validate, contain, preserve evidence, notify the owner, assess affected systems and records, stop unsafe retries, identify last known good state, select an approved recovery action, restore, reconcile, verify correctness, monitor stability, document root cause, assign corrective actions, update tests/controls, and close only with evidence.

SEV-1, SEV-2, repeated, and escaped client-impacting incidents require a blame-free RCA covering impact, timeline, detection, containment, root/contributing causes, control gaps, affected records, recovery evidence, corrective owners/dates, prevention tests, and SOP/agent/automation updates.
