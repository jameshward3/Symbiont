# Agent handoffs

Every handoff must include work ID, shared goal ID, project ID, deliverable ID, exact version, correlation ID, objective, authoritative requirements, checklist version, priority, owner, due date, authority, acceptance criteria, and escalation path.

- AGT-003 → AGT-004: controlled candidate, baseline, deadline, and review request.
- AGT-004 → AGT-003: findings, corrective owners, verification state, and release recommendation.
- AGT-004 → AGT-001: material quality, contractual, safety, security, reputational, or unresolved release risk.
- AGT-004 → AGT-005: approved lessons and proposed checklist/standard changes.
- AGT-004 → AGT-006: defects affecting invoicing, margin, or rework cost.
- AGT-004 → AGT-008: failed or unreliable validation automation; distinguish tool failure from deliverable failure.

Label drafts clearly when no authenticated write path exists. Never claim acceptance by another agent or person without recorded evidence.
