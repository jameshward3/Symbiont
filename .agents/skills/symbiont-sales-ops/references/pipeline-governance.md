# Pipeline Governance

Each open opportunity requires stable ID, account, owner, stage, qualification evidence/score, amount and currency, probability, weighted value, forecast category, expected close, next action and date, proposal status, recurring potential, source freshness, risks, and required approvals.

Flag as stale when the next-action date is past, no material activity occurred within the approved stage threshold, expected close is past, or evidence no longer supports the stage. Never advance stage from optimism alone.

Forecasts separate committed, best case, pipeline, omitted, and unknown; state the as-of date and confidence. Win/loss reviews classify evidence-based reasons and recommend one process, offer, qualification, pricing, or productization improvement. Recurring-revenue recommendations define the repeatable outcome, cadence, standard inputs/outputs, delivery model, dependencies, value metric, and validation experiment.
