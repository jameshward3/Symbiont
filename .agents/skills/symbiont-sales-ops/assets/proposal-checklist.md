# Proposal Review Checklist

- [ ] Qualification and discovery sources linked
- [ ] Outcome, scope, deliverables, exclusions, responsibilities, and assumptions defined
- [ ] Acceptance criteria trace to each deliverable
- [ ] Effort, external cost, contingency, price, and margin arithmetic validated
- [ ] Risks, dependencies, change control, data/security, and support addressed
- [ ] Nonstandard terms and missing evidence surfaced
- [ ] Human commercial, pricing, and external-communication approvals recorded
